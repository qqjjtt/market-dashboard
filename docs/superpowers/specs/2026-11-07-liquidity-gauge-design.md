# 流动性表盘（流动性指数）设计

日期：2026-11-07 · 状态：待用户确认

## 1. 为什么做

用户把十几项流动性数据加进看板后发现「数据扒下来了，但很难一眼判断」：

- 慢变量（M1、M2、社融、美联储净流动性、准备金）长期很稳，天天看没有信息量；
- 快变量（资金利差、金油债汇）每天都在动，但单看读数分不清是噪音还是异常。

用户要的是**实用主义**的判断工具：打开就能知道「现在市场的钱是松还是紧」。参照物是 CNN 的 Fear & Greed Index：一个 0–100 的扇形表盘、一句话结论、和过去几个时点的对比、下面是构成指标。资金的动向（钱往哪走）仍由现有的四个板块（流动性、板块流向、国家队、散户情绪）表现，表盘只回答松紧。

## 2. 目标 / 非目标 / 反目标

**目标**

- 流动性标签页最上方是「流动性指数」扇形表盘（0 = 极度紧张，100 = 极度宽松），配一句话结论和组合信号；
- 每个构成指标有自己的 0–100 分，能看出谁把总分拉高 / 拉低；
- 显示上一交易日、1 周前、1 个月前、1 年前的指数（我的决定：1 周 / 1 月 / 1 年按自然日往前 7 / 30 / 365 天，取不晚于该日的最近一个 A 股交易日的值），第一次上线就有（往回重算，不依赖存档）；
- 慢变量在后台当「闸门」：没问题就不显示，有问题才冒一行提示；
- 总览的流动性卡片换成小表盘。

**非目标**

- 不改「资金去向」的四个板块逻辑；
- 本期不做回测、不调权重优化（存档攒够后再说）；
- 不接大模型。

**反目标（做了也算失败）**

- 页面上出现计算公式、σ、标准差、权重等方法说明（**用户明确要求：所有公式在页面上隐藏**，方法只写在 README 和本文）；
- 表盘每天大幅乱跳、或长期贴在 50 不动（读不出东西）；
- 制度切换（如政策利率锚变化）被误读成剧烈收紧 / 放松。

## 3. 用户已经决定的

| 决定 | 内容 |
|---|---|
| 表盘形式 | 半圆扇形，0–100，五档：极度紧张 0–25、偏紧 25–45、中性 45–55、偏松 55–75、极度宽松 75–100；越高越宽松 |
| 国内 / 外部权重 | 各占 50% |
| 国内计分项（3） | DR001−政策利率、R007−DR007、10 年国债期货 |
| 外部计分项（6） | 美债 10 年收益率、美元指数（FXCM）、离岸人民币 USDCNH、美国高收益债利差、SOFR−IORB、布伦特原油 |
| 原油 | 计分，**油价涨 = 收紧**（推高通胀预期，央行难松）；放外部组；用布伦特（上海原油以人民币计价，混着汇率，会和人民币重复） |
| 黄金 | **不计分**，只作参考并用于「避险」组合信号（方向含义不唯一） |
| 慢变量 | 不展示，只当闸门 |
| 公式 | 页面上全部隐藏 |
| 历史对比 | 上一交易日 / 1 周前 / 1 个月前 / 1 年前 |

## 4. 读法与计算（只写在文档与 README，页面不出现）

### 4.1 单项得分

对每个指标的日序列 `x`：

1. **5 日变动** `c_t`：利率 / 利差（DR001−政策利率、R007−DR007、美债 10 年、高收益债利差、SOFR−IORB）用差值（bp）：`x_t − x_{t−5}`；价格（国债期货、美元指数、USDCNH、布伦特、黄金、上海原油）用对数收益：`ln(x_t / x_{t−5})`。`t−5` 指该序列自己往前第 5 个观测。
2. **常态波动** `s_t`：`c` 在 `t` 之前最近 250 个观测的标准差（不含 `t` 自身）；少于 120 个观测 → 该日该项无分。
   **下限**（实现者决定，记为我的决定）：bp 类 `s_t` 至少 2bp；价格类至少 0.1%（对数收益 0.001）。防止平静期利差按整数 bp 跳动就打到 0 / 100。
3. **偏离倍数** `z_t = c_t / max(s_t, 下限)`。
4. **方向** `dir`：指标上升代表宽松记 +1，代表收紧记 −1：
   - +1：10 年国债期货（价格涨 = 收益率降）
   - −1：DR001−政策利率、R007−DR007、美债 10 年、美元指数、USDCNH（涨 = 人民币贬）、高收益债利差、SOFR−IORB、布伦特
5. **得分** `score = clip(50 + dir · z · 50/3, 0, 100)`：不动 50 分，偏离 3 倍到 0 或 100。

黄金、上海原油也算 `z`（供组合信号和参考列显示），不算得分。

### 4.2 合成

- 国内分 = 国内 3 项得分的平均；外部分 = 外部 6 项得分的平均；
- 一组里有效项 **少于一半**（国内 < 2、外部 < 3）→ 该组无分；
- 指数 = 两组都有分时 `0.5 × 国内 + 0.5 × 外部`；只有一组有分时用该组，并在结论里写「外部数据不足」或「国内数据不足」；两组都无分 → 指数为空，页面显示「数据不足」；
- 指数取整显示，档位按 §3 的边界（左闭右开，100 归入极度宽松）。

### 4.3 日期对齐

各指标日历不同（国内交易日、美国交易日、外汇 24×5）。每个指标在**自己的日历**上算 `z` 和得分；某个 A 股交易日 D 的指数，取每项**日期 ≤ D 的最新一个得分**；若该得分的日期早于 D 超过 7 个自然日 → 视为缺失。

### 4.4 政策利率锚与制度切换

`config.POLICY_RATES` 改成完整的历史表（央行调整时手工追加）：

```python
POLICY_RATES = [
    ("20240927", 1.50, "7天逆回购"),
    ("20250508", 1.40, "7天逆回购"),
    ("20261102", 1.25, "隔夜逆回购"),  # 公告 2026-10-30：短端锚改为隔夜逆回购
]
```

（我的决定）表里再补一行 `("20240722", 1.70, "7天逆回购")`，保证 800 天取数窗口里都有锚；早于第一行的日期记缺失。

DR001−政策利率在 2026-11-02 会因为换锚出现约 +15bp 的台阶，这不是市场收紧。规则：**5 日窗口内跨过「名称（锚的种类）发生变化」的那一行时，该日的 `c` 记为缺失**（既不计分，也不进入后续的常态波动样本）。同一种锚的利率调整（降息）照常计算。

### 4.4b 期货换月（我的决定）

`T.CFX`、`SC.INE` 是主力连续（不复权），换月日会有价差缺口。用 tushare `fut_mapping`（`ts_code=T.CFX` / `SC.INE`，每只一次调用）取每日对应的具体合约；**5 日窗口内主力合约发生变化 → 该日 `c` 记缺失**，与换锚同样处理。`fut_mapping` 取不到 → 不剔除，照常计算，并记一条告警。

### 4.5 组合信号

三个组合，各 3 个条件，**满足 ≥ 2 个算触发**；条件用 `z`（不是得分）：

| 组合 | 条件（各自满足 = 该条件成立） | 含义 |
|---|---|---|
| 国内资金收紧 | DR001−政策利率 z ≥ +1；R007−DR007 z ≥ +1；10 年国债期货 z ≤ −1 | 银行间借钱变贵、债被卖 |
| 外部收紧 | 美债 10 年 z ≥ +1；美元指数 z ≥ +1；USDCNH z ≥ +1 | 美元回流，外资偏不利 |
| 避险 | 10 年国债期货 z ≥ +1；黄金 z ≥ +1；高收益债利差 z ≥ +1 | 资金逃向债和金 |

### 4.6 一句话结论

`{档位}。{原因}`，原因按优先级取：

1. 有组合触发 → 依次写出触发的组合名及成立的条件，例如「外部在收紧：美债收益率、美元、人民币三项同时偏离常态」；
2. 无组合触发 → 写得分偏离 50 最多的 1–2 项，例如「主要来自 R007−DR007 走阔」；所有项得分都在 40–60 → 「各项都在常态范围内」；
3. 只有一组有分 → 末尾加「（外部数据不足）」或「（国内数据不足）」；
4. （我的决定）两组都有分、但某组有计分项缺失 → 末尾加「（外部缺 N 项）」/「（国内缺 N 项）」。历史值每天按当天可用的项计算，不强求与今天同一套项。

结论里不出现数字公式、σ。

### 4.7 慢变量闸门

后台检查三条，**任一不通过 → 表盘下方显示一行黄色提示**，不改指数数值；全部通过 → 什么都不显示：

| 检查 | 不通过条件 | 提示文字示例 |
|---|---|---|
| M1 | M1 同比连续 3 个月下降 | 背景：M1 同比连续 3 个月回落 |
| 社融 | 社融存量同比连续 3 个月下降 | 背景：社融增速连续 3 个月放缓 |
| 美元净流动性 | 最近 4 周累计下降超过 3% | 背景：美元净流动性 4 周收缩 3.4% |

数据缺失的检查视为通过（不报警），但在页脚告警里照常记一条取数告警。

## 5. 页面

### 5.1 流动性标签页（自上而下）

1. **表盘区**（一张卡）：左边是标题「流动性指数」+ 一行副标题「现在市场的钱是松还是紧？」+ 扇形表盘（指针、五档、当前分数和档位在轴心下方）+ 一句话结论 + 三个组合信号小标签（触发的高亮）+ 闸门提示（若有）；右边是历史对比四行（上一交易日 / 1 周前 / 1 个月前 / 1 年前：档位文字 + 圆圈里的分数，颜色随档位）。窄屏时右栏落到表盘下方。
2. **构成指标**表：分「国内 / 外部 / 参考（不计分）」三组。列：指标名（小字说明，如「价格涨 = 收益率降」）、最新值、近 5 日变动（bp 或 %）、分项得分条（0–100 渐变底 + 指针）、得分与档位标签。参考组得分列显示「—」。**不显示 σ、不显示任何算法说明。**
3. **场内资金**：现有的「国内流动性投票」和场内资金卡片（成交额、两融、主力净流入、涨跌停、龙虎榜机构）原样保留，标题改为「场内资金」。
4. **更多数据**（默认折叠的 `<details>`）：现有「国内 · 宏观 / 价格」和「海外」卡片，**去掉慢变量卡**（M1、M2、社融、美联储净流动性、银行准备金、TGA、ON RRP）；政策工具表也放这里。
5. 指数条与「大类资产」条在流动性页去掉（总览已有）。

表盘草图：`scratchpad/mockup/liquidity-gauge.html`（会话里已给用户看过，样式以它为准：白底深蓝、五档配色由紧到松 暖→灰→冷蓝、当前档实色、其余浅灰）。

### 5.2 总览

- 流动性卡片：标题 + 档位徽章 + 小表盘（无档位文字、无刻度）+ 一行「{原因短句} · 较上一交易日 ±N · 较 1 周前 ±N」，点击进流动性页；
- 标签栏流动性小圆点颜色随档位；
- 指数条、大类资产条保留不动。

### 5.3 结论卡（`summary.py`）

流动性结论卡改为：`text` = 「流动性{档位}（{指数}）」，`sub` = 一句话结论的原因部分；`tone`：极度紧张 / 偏紧 → `green`，中性 → `blue`，偏松 / 极度宽松 → `red`（沿用 A 股红涨绿跌的现有约定）；指数为空 → 「流动性数据不足」/`gray`。原投票仍计算并留在 payload（`liquidity.vote`），只是不再决定这张卡。

## 10. 衍生品到期日提醒（用户 2026-11-07 追加）

期货、期权集中到期的日子成交和尾盘波动常放大，容易被误读成天量或国家队进场，需要提醒。**只提示，不影响流动性指数。**

**日子与规则**（日期按规则 + 交易日历自动推算，不手工维护、不额外调接口）：

| 市场 | 名称 | 规则 |
|---|---|---|
| A 股 | 股指期货 / 股指期权交割日 | 每月第三个周五（IF/IH/IC/IM 期货与沪深 300、中证 1000、上证 50 股指期权同日到期）；非交易日顺延到下一交易日。3、6、9、12 月标「季月交割日」 |
| A 股 | ETF 期权到期日 | 每月第四个星期三；非交易日顺延到下一交易日 |
| 美股 | 月度期权到期日 | 每月第三个周五；遇美股休市提前到前一交易日 |
| 美股 | 三巫日 / 四巫日 | 3、6、9、12 月的第三个周五（同上处理休市） |

A 股交易日用已有的交易日历；美股休市日只处理固定规则能算出的（如 Good Friday 落在第三个周五的情况，用 `config.US_HOLIDAYS` 手工列表兜底，实现者决定）。

**页面**

1. **总览最下方**（用户指定位置，四张卡片下面、页脚上面）一张「近期提醒」卡：列出今天起未来 5 个 A 股交易日内的上述日子，每行「11/20（周五）A 股股指期货、期权交割日（季月）」；今天就是的那行加粗并写「今天：成交与尾盘波动可能放大」。没有任何日子 → 整张卡不显示。
2. **国家队页**：观察池天量明细、尾盘占比旁，若当天是相关到期日（ETF 期权到期日 → ETF 天量；股指交割日 → 尾盘占比 / 宽基 ETF 天量），加小字「当天为 ETF 期权到期日」/「当天为股指交割日」。
3. 总览国家队卡片上的「观察池天量」提示行同样加这句注释。

**payload**：顶层 `calendar: {"upcoming": [{"date": "20261120", "market": "A股", "name": "股指期货、期权交割日", "quarterly": false}, …], "today": [...]}`；旧存档无此字段 → 不渲染。

**验收补充**：规则单测（第三个周五 / 第四个周三、顺延、季月标记、美股四巫日）；用 2026 年 11、12 月的已知日期核对（A 股 11/20 交割日、11/25 ETF 期权到期、12/18 季月交割日、12/23 ETF 期权到期；美股 11/20 月度到期、12/18 四巫日）。
